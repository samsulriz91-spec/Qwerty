# Jurnal Pro Trader

Build only the Home prototype until the user explicitly expands the scope.
Before frontend design work, read `.agents/skills/frontend-design/SKILL.md`.
Use Indonesian interface copy, the Calm Cockpit graphite/lavender tokens in DESIGN.md,
and mobile-first navigation.
Treat every displayed account and trade as demo data. Do not imply a live connection.
Calculate all displayed metrics from one dataset. Account balance is all-time;
period filters scope metrics, chart, and recent trades. Monthly targets and daily
discipline retain their own explicitly labelled periods.
Call a chart of closed-trade balances a balance chart, not live equity.
Do not add login, backend, OCR, or other pages without user direction.
Check phone layouts, keyboard use, period filtering, and metric consistency before saving.

https://github.com/anthropics/skills/tree/main/skills/frontend-design.
